# EMRALD 1.3.0

New: custom effort levels (Pro). Alongside E1-E4, Pro users can now define
their own effort levels at any 5% step of daily work time — named, colored,
and available everywhere levels appear: pickers, project badges, the
timeline marker, and the E-Level Overview. Manage them in Settings →
Manage effort levels.

Improvements:

- Settings tab rebuilt on Obsidian's declarative settings API — EMRALD
  settings now appear in Obsidian's global settings search. Requires
  Obsidian 1.13+.
- Sessions now auto-pause two hours past the day's prescribed effort, with
  a notice — resume anytime if you're still going.
- The burnout warning can now open the Burnout Monitor view directly
  ("Show me the data").
- Small fixes: slider values shown inline, clearer wording when a level's
  percent can't be changed, assorted picker polish.
